Privacy Policy

Last Updated: September 2025

Overview

BitpieCounter is a Chrome extension designed to provide fast, secure, and convenient utilities like JSON formatting and CSV conversion. We do not collect, sell, or share any personal data. All operations happen locally in your browser.

Data Collection

We do not collect or transmit any personal information.

  • No personal identifiers (name, email, etc.)
  • No browsing history or keystrokes
  • No analytics, ads, or trackers

Any text you process using this extension stays on your device. If you copy results, they are placed only on your system clipboard.

Permissions

Permission Why It’s Required What It Does Not Do

https://firestore.googleapis.com/*		 Used to fetch a read-only JSON configuration file from our Firebase project. This file contains simple settings (e.g., whether to show built-in tools or open a webpage). It allows us to update options without requiring users to reinstall the extension. ❌ Does not access user data or websites
❌ No tracking, ads, or analytics
✅ Only retrieves a safe static JSON file
✅ No remote JavaScript is executed

Third-Party Content

In some cases, the extension may open or embed our official site (constavids.github.io/BitpieCounter/). That website may have its own policies regarding cookies or logs.

For Chrome Web Store Reviewers

- No personal or browsing data is collected.
- Firebase is only used to fetch static JSON configuration.
- The extension never executes remote code.
- Permission scope is minimal and necessary only for configuration.
